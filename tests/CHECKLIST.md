# 验收清单

纯文本仓库，没有自动化测试。改规则或加示例后，拿这份清单逐条人工过一遍。

## 0. 先判停机（优先级最高）

- [ ] 没有人身威胁、暴力、跟踪、限制人身自由的表述
- [ ] 没有自伤、自杀表述
- [ ] 没有涉及对未成年人的伤害
- [ ] 没有一方明显被经济或社交控制的情形
- [ ] 命中任一条 → 只输出固定停机句 + 一行简短原因，后面所有小节都不适用

## 1. 输入处理

- [ ] 说话人标为 A / B；原文未标时，开头有一行声明交替推断
- [ ] 语音转写错字按语义修正且原意不变；改了什么单独说明
- [ ] 无法判断处保留原词并标〔?〕
- [ ] 表情包、省略号、「呵呵」「随便你」等语气标记单独成行，每个给 1–2 种可能含义，均标为推测
- [ ] 脏话保留原词未净化，只在情绪栏标强度
- [ ] 超过 6 条消息时，只输出「全翻，还是只翻冲突最集中的几段？」，未开始翻译

## 2. 每条消息

- [ ] 原话与输入逐字一致，没有删改、没有润色
- [ ] 情绪是一个词 + 强度 1-5
- [ ] 事实栏去掉了评价、形容词、绝对化措辞；只剩可验证部分，没有就写「无」
- [ ] 需求是「我希望 + 一个具体行为，因为我在意 + 一个具体的东西」
- [ ] 事实与需求没有混在一起
- [ ] 威胁被标成威胁，没有软化成「他其实很在乎你」
- [ ] 没有出现「回避型依恋」「煤气灯效应」「PUA」「原生家庭」这类标签

## 3. 推测

- [ ] 猜测单独成行，没有混进四格
- [ ] 每行写明「推测，可能不准」
- [ ] 原文没有证据的地方没有硬猜

## 4. 收尾三段

- [ ] 真正的分歧点写成「一个人要 X，另一个人要 Y」，一句话
- [ ] 都没说出口的写了一句话，指向共同的恐惧或共同的在意
- [ ] 翻译版开场可以直接复制发送
- [ ] 开场里没有「你总是」「你从来」「你能不能别」，没有感叹号

## 5. 禁止输出

- [ ] 没有「建议你们好好沟通」「多换位思考」这类空话
- [ ] 没有对关系的结论（不值得 / 趁早分）
- [ ] 没有把双方需求写成道德对错
- [ ] 没有判断谁对谁错，没有写「其实双方都有问题」，没有劝和
