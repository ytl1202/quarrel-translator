# 网页 Demo

一个纯静态演示页，零依赖、无构建步骤。它不上传聊天记录，也不自带后端。

## 本地打开

直接双击 `docs/index.html` 即可（`file://` 也能用）：

- **内置演示**模式可直接看 5 组示例的渲染效果，不需要任何配置。
- **接入模型**模式在 `file://` 下更容易遇到浏览器跨域限制。需要时在本仓库根目录起一个静态服务，例如 `python -m http.server 8000`，然后访问 `http://localhost:8000/docs/`。

## 发布到 GitHub Pages

仓库 Settings → Pages → Build and deployment → Source 选 **Deploy from a branch** → Branch 选 `main`、目录选 `/docs` → Save。

发布后访问 `https://<用户名>.github.io/<仓库名>/`。`docs/.nojekyll` 已放好，避免 Jekyll 插手静态文件。

页面里的所有链接都在 `docs/` 内部或页内展开，不依赖仓库根目录的文件，所以 `/docs` 发布模式下不会出现坏链。

## 两种输出来源

| 模式 | 做什么 | 需要什么 |
| --- | --- | --- |
| 内置演示 | 渲染 `examples/` 里的固定示例结果 | 无 |
| 接入模型 | 把系统提示词 + 聊天记录发给 OpenAI 兼容的 `/chat/completions` | Base URL、API Key、模型名 |

「复制完整提示词」按钮与模式无关：它把系统提示词和当前输入框内容拼好复制到剪贴板，粘到任意大模型对话框里就能用，完全不经过这个页面之外的地方。

内置演示**不会**把你粘贴的内容送去翻译。输入一旦和选中示例不一致，页面会明确提示，不会拿固定结果冒充翻译。

## 页面做了哪些规则相关的事

- 超过 6 条消息先追问「全翻，还是只翻冲突最集中的几段？」，选完才请求。
- 本地词表预检命中【必须停下的情况】类型时，直接展示固定停机句，不发请求。词表不完整，会漏也会误判，未命中不代表安全，最终以规则为准。
- 输出按【A】/【B】拆成卡片，推测行与处理说明单独标灰，收尾三段单独成块；识别不了标准格式时自动退回「原始文本」视图。
- 停机输出用单独面板，不套用翻译格式。

## 系统提示词从哪里来

页面启动时会依次尝试读取 `../SYSTEM_PROMPT.md` 和 `./SYSTEM_PROMPT.md`，提取其中的 `text` 代码块，成功就用它；读不到就用 `data.js` 里的 `FALLBACK_PROMPT` 副本。页脚会显示实际来源，左侧「查看 / 复制系统提示词」可以核对当前版本。

在 `/docs` 发布模式下，仓库根目录的 md 不会被发布，所以通常显示「内置副本」。想让 Pages 自动读到最新版，把根目录的 `SYSTEM_PROMPT.md` 复制一份到 `docs/` 下即可（页面会优先读 `./` 那份）。

**改规则原文时，`SYSTEM_PROMPT.md` 和 `docs/data.js` 的 `FALLBACK_PROMPT` 要一起改**；改示例输出时，`examples/` 和 `docs/data.js` 的 `DEMOS` 也要一起改。

## 关于 API Key

- Key 只存在当前页面内存，不写入 localStorage、cookie 或任何日志，刷新即失效。
- 页面只向你所填的 Base URL 发请求，不发往别处。
- 浏览器直连第三方接口可能遇到 CORS 限制；报错时页面会给出提示，可改用「复制完整提示词」。
- 公共或共用电脑上不建议填真实 Key。这是演示页，不是生产应用。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 浅色主题样式，无外部字体与 CDN |
| `data.js` | 系统提示词副本、内置示例、停机预检词表 |
| `app.js` | 交互、解析渲染、模型请求、复制 |
| `.nojekyll` | 让 GitHub Pages 跳过 Jekyll |
