它在做什么

下面是仓库内置示例的真实输出形式（示例为中文原话）

输入 · 聊天截图 / 文字
你从来都不回我消息，你心里根本没我。
我上班忙，你能不能别无理取闹。
随便你吧
→
输出 · 情绪 / 事实 / 需求
【A】原话：你从来都不回我消息，你心里根本没我。
情绪委屈（4/5）
事实过去 24 小时有消息未获回复（需核对）
需求我希望忙的时候给我一句「晚点回」
推测怕的是「我不重要」，不是「你不回」

隐私与边界

这三件事在使用前就该知道

截图

图片会离开浏览器

页面不做本地 OCR，截图以 base64 发往你自己填写的模型端点。发之前先遮掉头像、昵称、手机号。

凭据

Key 只在当前页面内存

不写入本地存储、不发往除你所填端点以外的地址。公共或共用电脑上不要填真实 Key。

停机

有些对话不翻译

命中人身威胁、自伤、涉及未成年人伤害、经济或社交控制时，立刻停机，只输出一句提示和简短原因。

六个特性

全部是纯文本和静态页面，没有服务端

三份提示词

逐句翻译、聊天截图读图、推荐回复，各自独立可复制，按需组合。

截图读图

按气泡左右推断说话人并声明是推测，过滤时间戳与系统灰字，表情包单独解释。

推荐回复

克制版 / 直说需求版 / 先缓一缓版，每条附一句说明，可单独复制。

五条铁律

不站队、不脑补、不改事实、不诊断、不软化攻击性。

停机优先

安全红线命中时不逐句翻译、不给回复建议，也不下关系结论。

零依赖

没有框架、CDN 和构建步骤；双击 HTML 就能用，也可以直接用 GitHub Pages 发布。

快速开始

不想配任何东西，就直接用在线工具里的内置示例

# 1. 复制提示词到大模型的系统提示词位置
SYSTEM_PROMPT.md          # 逐句翻译聊天记录
+ SCREENSHOT_PROMPT.md    # 输入是截图时，接在上面那份之后
REPLY_PROMPT.md           # 想要推荐回复时，改用这一份

# 2. 或者打开在线工具（内置示例不需要 API Key）
https://ytl1202.github.io/quarrel-translator/app.html

# 3. 本地看源码
git clone https://github.com/ytl1202/quarrel-translator.git

已知限制

  • 截图板块需要模型支持图片输入，且端点要接受 data URL 形式的 base64 图片。
  • 图片里的内容无法做本地停机预检，词表兜底会漏也会误判。
  • Pages 站点即使源仓库是私有的，也仍然公网可访问。
  • 规则内置示例的事实栏含演示占位数字；新增示例按更严格的规则文字书写。
