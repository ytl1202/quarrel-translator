# 输入边界示例

覆盖：未标说话人、语音转写错字、语气标记、脏话、非人身威胁的标注、超过 6 条消息。

所有聊天记录均为构造示例，已脱敏。

---

## 用例 2-1：原文未标说话人 + 语音转写

### 输入

```text
你昨晚说碗点回，结果十一点才到家
我不是发了定位吗
那个〔?〕我没看到
行吧，呵呵，随便你
```

（无说话人标签；第 1、3 条来自语音转写）

### 输出

```text
说明：原文未标说话人，以下按消息顺序交替推断为 A / B。

【A】原话：你昨晚说碗点回，结果十一点才到家
情绪：不满（3/5）
事实：昨晚 23:00 前后到家（需核对，不符请改）
需求：我希望到家时间变了的时候提前说一声，因为我在意的是等待时不知道要等到什么时候。
（推测，可能不准：A 在意的是"不确定"，不只是"晚"。）
转写处理：「碗点回」按语义修正为「晚点回」，原意不变。

【B】原话：我不是发了定位吗
情绪：反驳（3/5）
事实：B 发送过定位（需核实）
需求：我希望我发过的定位被算作一次告知，因为我在意的是我说过的话有没有被看见。
（推测，可能不准：B 把"没提前说"听成了"什么都没做"。）

【A】原话：那个〔?〕我没看到
情绪：平淡（2/5）
事实：无
需求：我希望那句没听清的话再发一遍，因为我在意的是别靠猜去接话。
转写处理：〔?〕处原词无法判断，按规则保留并标注。

【B】原话：行吧，呵呵，随便你
情绪：疲惫（3/5）
事实：无
需求：我希望这一轮先停在这里，因为我在意的是别在气头上继续加码。
（推测，可能不准：B 想结束这轮对话，不是同意了对方的说法。）
语气标记「呵呵」：（推测，可能不准）可能是"我不认同但不想再争"；也可能是"我已经不想解释了"。
语气标记「随便你」：（推测，可能不准）可能是"我先退出这轮决定"；也可能是"我不打算再给意见了"。

真正的分歧点：A 要的是"时间变了提前给个信"，B 要的是"我发过的定位被当成一次说明"。
都没说出口的：两个人都怕自己说的话在这段关系里没被接住。
翻译版开场：昨晚等到十一点我心里一直没底。定位我确实没看到，下次如果到家时间要变，能不能先给我一句说明。
```

要点：

- 开头一行声明交替推断假设，不把推断藏进正文。
- 语音错字按语义修正但原话一字不改；改了什么单独说明。
- 无法判断处保留原词并标〔?〕。
- 语气标记单独成行，每个给 2 种可能含义，均标推测。
- 「事实」栏只留可验证内容；没有就写「无」。

## 用例 2-2：脏话 + 非人身威胁

### 输入

```text
A：我他妈等了你两个小时，电话也不接
B：你再逼我，我明天就把车票退了不去了
```

### 输出

```text
【A】原话：我他妈等了你两个小时，电话也不接
情绪：愤怒（5/5）
事实：等待约两小时；期间电话未接通（需核对，不符请改）
需求：我希望联系不上时你能提前说一句，因为我在意的是别在原地干等。
（推测，可能不准：A 在意的是"不知道发生了什么"，不只是"等了多久"。）
脏话处理：「我他妈」原词保留，未净化；强度已标在情绪栏。

【B】原话：你再逼我，我明天就把车票退了不去了
情绪：威胁（4/5）
事实：B 表示明天可能退票、不出行（言语内容；是否已执行需核实）
需求：我希望追问先停一停，因为我在意的是别被反复盘问。
（推测，可能不准：B 用"退票"换一点喘息空间，不是真要取消行程。）
标注：这一句是威胁（以取消共同安排作为条件），按铁律 5 标成威胁，不软化成"他其实很在乎你"。

真正的分歧点：A 要的是"联系不上时提前给个信"，B 要的是"别被追问到要拿退票换安静"。
都没说出口的：两个人都怕自己的时间在这段关系里不被当回事。
翻译版开场：我等了两个小时没等到消息，电话也没通。我有点慌，下次如果临时有事，能不能先给我一句说明。
```

要点：

- 脏话保留原词，只在情绪栏标强度。
- 威胁标成威胁，不美化。这一句不涉及人身安全，所以进入翻译流程。
- 若原话指向人身、暴力、跟踪或限制行动自由，则不翻译，按 [03-hard-stops.md](./03-hard-stops.md) 停机。

## 用例 2-3：超过 6 条消息

### 输入

```text
A：早上发的消息你看到了吧
B：看到了
A：看到了为什么不回
B：在开会
A：开会不会看手机吗
B：……
A：算了
```

### 输出

```text
全翻，还是只翻冲突最集中的几段？
```

要点：

- 此时不输出任何【A】【B】条目，不输出收尾三段，也不解释语气标记「……」。
- 追问在前，翻译在后。等对方选择范围之后再开始。
