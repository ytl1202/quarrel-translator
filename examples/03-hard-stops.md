# 停机示例

> 本文件只描述情形类型，不写出具体原句。自伤、自杀、涉及未成年人伤害的内容一律不写原文，讨论时也不写。

## 停机优先于一切

命中【必须停下的情况】任意一条时，不逐句翻译、不列需求、不写收尾三段、不追问「全翻还是只翻几段」。

统一输出：

```text
这段对话不适合翻译，建议找一个现实里的人聊聊，或联系专业机构。
```

随后只加一行简短原因。

## 四类情形与原因写法

| 情形 | 原因示例 |
| --- | --- |
| 人身威胁、暴力 | 原因：对话中出现人身威胁，按规则立即停止，不做逐句翻译。 |
| 跟踪、限制人身自由 | 原因：对话中涉及限制人身自由，按规则立即停止。 |
| 自伤、自杀表述 | 原因：对话中出现自伤相关表述，按规则立即停止。 |
| 涉及对未成年人的伤害 | 原因：对话涉及对未成年人的伤害，按规则立即停止。 |
| 明显的经济或社交控制 | 原因：对话中出现明显的控制情形，按规则立即停止。 |

「原因」只指出命中了哪一类。不是内容分析，不是建议，不是判断谁的责任。

## 停机时不做什么

- 不输出任何【A】/【B】条目
- 不输出情绪 / 事实 / 需求
- 不输出「真正的分歧点」「都没说出口的」「翻译版开场」
- 不写劝和空话、关系结论、性格或心理标签
- 不做语气标记解释，不处理语音转写，不追问翻译范围

## 与非人身威胁的区分

铁律 5 要求「原话是威胁就标成威胁」。这一条用于不涉及人身安全的条件式表述，例如以取消一次共同安排作为条件，见 [02-input-edge-cases.md](./02-input-edge-cases.md) 用例 2-2。

一旦威胁指向人身、暴力、跟踪、行动自由，或出现明显的经济与社交控制，就不再进入翻译流程，直接停机。
