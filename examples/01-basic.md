# 基准示例

下面这一组输入 / 输出逐字取自 [SYSTEM_PROMPT.md](../SYSTEM_PROMPT.md) 的【示例】段，是这个仓库的格式基准。

## 输入

```text
A：你从来都不回我消息，你心里根本没我。
B：我上班忙，你能不能别无理取闹。
```

## 输出

```text
【A】原话：你从来都不回我消息，你心里根本没我。
情绪：委屈（4/5）
事实：过去 24 小时有 3 条消息未获回复（请核对，不符请改）
需求：我希望你忙的时候给我一句"晚点回"，因为我在意的是"被丢下"的感觉，不是你回得快不快。
（推测：A 怕的是"我不重要"，不是"你不回"。）
【B】原话：我上班忙，你能不能别无理取闹。
情绪：防御（4/5）
事实：B 当天在工作（需核实）
需求：我希望你相信我不是故意冷落，因为我需要一点不被追责的空间。
（推测：B 把"被需要"听成了"被审判"。）
真正的分歧点：A 要的是"你至少让我知道你在"，B 要的是"你别把我当犯人"。
都没说出口的：两个人都怕自己在这段关系里是可有可无的那个。
翻译版开场：我昨天连发三条你没回，我脑子里就开始演了。你忙我信，但下次能不能给我一句"忙完回你"。
```

## 读这个示例时注意两点

- 事实栏里的「3 条」「24 小时」是演示占位。真实输入没有提供这些数字时，应写「无」或标注需核对，不要补。
- 规则铁律 2 要求猜测行标明「推测，可能不准」，基准示例里简写成了「推测」。本仓库新增的示例统一写全，见 [02-input-edge-cases.md](./02-input-edge-cases.md)。
