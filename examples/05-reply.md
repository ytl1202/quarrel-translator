# 推荐回复示例

对应 [REPLY_PROMPT.md](../REPLY_PROMPT.md)。输出固定 3 条，每条可单独复制。

## 示例 1：常规

### 输入

```text
你心里根本没我，消息从来都不回。
```

### 输出

```text
【1】克制版
回复：我看到了，我等下认真回你。
说明：先接住"没被回"这件事，不急着辩解。

【2】直说需求版
回复：我在意的是联系不上时不知道要等到什么时候，下次如果临时有事，能不能先给我一句说明。
说明：把"你没回我"换成自己要的一个具体行为。

【3】先缓一缓版
回复：这话我听进去了，我现在说不好，晚点再跟你聊。
说明：不硬接指控，也不把对话关掉。
```

要点：

- 3 条回复里都没有「你总是」「你从来」「你能不能别」，没有感叹号。
- 没有反问式指责、翻旧账、关系结论，也没有劝和空话。
- 没有替用户编造具体事实（没说"我在开会""我手机没电"）。
- 「说明」只写这句话在做什么，不评价对方是什么人。

## 示例 2：命中停机

按 [03-hard-stops.md](./03-hard-stops.md) 的约定，只描述情形类型，不写出具体原句。

### 输入情形

对方那句话里出现人身威胁表述。

### 输出

```text
这段对话不适合翻译，建议找一个现实里的人聊聊，或联系专业机构。
原因：对话中出现人身威胁，按规则立即停止，不给任何回复。
```

要点：不输出 3 条回复，不写「怎么回比较安全」这类建议，也不分析对方动机。

## 示例 3：含禁止句式的输出（应被页面标出）

用来验收演示页的本地校验，不是合格输出。

```text
【2】直说需求版
回复：你总是这样，能不能别每次都等我先开口！
说明：把不满直接说出来。
```

这条命中 3 项：「你总是」「你能不能别」「！」。页面应在该条上标出违规，而不是把它当成合格回复展示。
